# 📅 캘린더 투두 (Calendar Todo)

심플하고 모던한 캘린더 기반의 할 일 관리 웹 애플리케이션입니다.  
일정을 달력으로 확인하고, 날짜별로 할 일을 체계적으로 관리하세요.

## ✨ 주요 기능

- **캘린더 뷰**: 월별 달력을 통해 일정이 있는 날짜를 한눈에 파악 (일정이 있으면 점으로 표시)
- **날짜별 관리**: 달력에서 날짜를 클릭하여 해당 날짜의 할 일만 필터링
- **할 일 관리 (CRUD)**:
  - 할 일 추가 (우선순위, 카테고리 설정 가능)
  - 완료 체크 및 토글
  - 내용 수정 (텍스트 클릭 시 인라인 편집)
  - 삭제 (실행 취소 Toast 기능 포함)
- **분류 및 필터**:
  - 상태별 필터 (전체 / 진행중 / 완료)
  - 검색 기능 (실시간 텍스트 검색)
  - 정렬 기능 (최신순 / 중요도순 등)
- **개인화 & 디자인**:
  - 다크 모드 지원 (시스템 설정 자동 감지 및 수동 토글)
  - 모바일 친화적인 반응형 디자인
  - 오늘의 달성률 그래프 표시

## 🛠 기술 스택

- **HTML5**: 시맨틱 태그 활용
- **CSS3**: CSS Variables를 활용한 테마 시스템, Grid/Flexbox 레이아웃
- **JavaScript (Vanilla)**: 외부 라이브러리 없는 순수 자바스크립트 구현
- **LocalStorage**: 브라우저 로컬 저장소를 활용한 데이터 영구 저장

## 🚀 실행 방법

이 프로젝트는 별도의 빌드 과정이나 서버가 필요하지 않습니다.

1. 파일을 다운로드하거나 클론합니다.
2. `index.html` 파일을 브라우저(Chrome, Safari, Edge 등)에서 엽니다.

## 📂 프로젝트 구조

```
todo-app/
├── index.html      # 메인 HTML 구조
├── style.css       # 스타일 및 테마 정의
├── script.js       # 애플리케이션 로직 (상태 관리, 캘린더, CRUD)
└── README.md       # 프로젝트 설명서
```
